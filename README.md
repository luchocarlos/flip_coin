flip_coin

Esta aplicación muestra una interfaz básica con un botón para lanzar la moneda y ver el resultado aleatorio; Diseñada para https://devchallenges.io/

Cómo funciona?

Al hacer clic en el botón, se ejecuta una función de JavaScript que genera un valor aleatorio y actualiza la interfaz con el resultado.


🛠 Tecnologías usadas

- 🧱 HTML – estructura de la página web  
- 🎨 CSS – estilos y diseño visual  
- ⚙️ JavaScript – lógica para simular el lanzamiento de la moneda
